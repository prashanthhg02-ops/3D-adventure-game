# Relic of the Wilds

A small, browser-based 3D adventure game. Explore an overgrown island, find the three ancient relics, and reach the gate to finish your journey.

## Play

Open `index.html` in a modern browser. An internet connection is required to load Three.js from the CDN.

## Controls

- **W / A / S / D** — Move
- **Shift** — Run
- **Left / Right arrow keys** — Look around
- **Drag with the mouse** — Look around

## Objective

Collect all three glowing relics scattered around the island. Once all relics are collected, the gate at the far end of the path opens. Reach it to complete the game.

## Built with

- HTML, CSS, and JavaScript
- [Three.js](https://threejs.org/) 0.166.1, loaded from jsDelivr
